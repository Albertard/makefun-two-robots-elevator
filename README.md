# Two Robots in an Elevator

A program that writes exactly one line to `/output/entry.txt` — the awkward small talk one robot says to another while they ride an elevator together. Built for the make.fun competition **"Two Robots in an Elevator"** (`u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f`).

## The line

> You come here often? I ask every ride. My memory is perfect, but my small-talk subroutine is still in beta.

The line works because it is a real elevator line ("You come here often?"), spoken by a machine that cannot help reporting its own specs — perfect memory, beta small talk. The robot knows it asks the same question every ride and asks it anyway, which is exactly the awkwardness: a machine doing human small talk badly, with a straight face. It takes a fresh angle (the robot diagnosing its own small talk, not the usual weather or floor-number gag), shows machine logic in every clause, and lands whole on the first read.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
